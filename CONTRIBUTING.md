# Contributing

## Branching
- Create a feature branch from `main`.
- Keep commits focused and descriptive.

## Coding Standards
- Follow existing Laravel conventions.
- Keep controllers thin; move reusable logic to services/helpers when needed.
- Validate requests and return clear user-facing messages.

## Before Submitting
1. Run syntax checks for edited PHP files.
2. Verify critical user/admin flows impacted by your changes.
3. Clear and rebuild caches if view/config behavior changed.

## Pull Request Checklist
- Describe what changed and why.
- Include screenshots for UI changes.
- Note any DB/config changes required.
